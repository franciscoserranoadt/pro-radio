# Pro Radio

Radio online con emisoras de todo el mundo para la pantalla Android del coche (Junsun).

- Catálogo mundial gratuito (Radio Browser): países, géneros y búsqueda por nombre o por voz.
- 30 memorias (3 bancos de 10) y favoritas.
- Mandos al volante: play/pausa, siguiente y anterior (recorren las memorias).
- Suena en segundo plano, se reconecta sola en túneles y arranca con la última emisora.
- Temperatura exterior y clima por GPS (Open-Meteo).

## Descargar
Cada cambio en `main` compila el APK automáticamente: **Releases → ProRadio.apk**.
